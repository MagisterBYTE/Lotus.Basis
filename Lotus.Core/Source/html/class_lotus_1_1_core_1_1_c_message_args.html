Detailed Description

Базовый класс для определения аргумента сообщения.

Фактические данный класс реализует полноценное хранение данных о произошедшем событии, источники событии. Чтобы исключить накладные расходы связанные с фрагментацией памяти малыми объектами, объекты классы управляются через пул. Таким образом фактически происходит циркуляция сообщений в системе без существенных накладных затрат
