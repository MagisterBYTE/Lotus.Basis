Detailed Description

Класс для реализации группы задач.

Под группой задач понимается несколько задач выполняемых параллельно или последовательно определённым способом с возможностью задержки начала выполнения задач, паузой, информирования об окончании выполнения всех задач группы, и принудительной остановкой выполнения группы задачи.
