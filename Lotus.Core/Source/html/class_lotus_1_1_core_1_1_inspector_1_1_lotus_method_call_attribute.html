Detailed Description

Атрибут для определения возможности вызова метода объекта через инспектор свойств.

Поддерживается до двух аргументов метода. Аргументы должны быть сопоставимы с типом CVariant. Отображение вызываемых методов в инспекторе свойств происходит после отображения всех данных
