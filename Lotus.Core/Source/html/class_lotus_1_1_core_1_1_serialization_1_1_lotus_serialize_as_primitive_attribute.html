Detailed Description

Атрибут для информирование о том что тип сериализуется как примитивный.

В контексте текстового потока данных это означает что он может быт записан в одну строку (в формат атрибута XML) Тип помеченный данным атрибутом должен обязательно реализовать статический метод с именем LotusSerializeAsPrimitiveAttribute.DESERIALIZE_FROM_STRING и обычный метод с именем LotusSerializeAsPrimitiveAttribute.SERIALIZE_TO_STRING
