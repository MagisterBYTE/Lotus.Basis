Property Documentation

◆ IsFill

bool Lotus.Core.SparseSet< TItem >.IsFill
get

Статус заполненной коллекции.

Статус заполненной коллекции означает то на текущий момент текущее количество элементов равно максимальному и при следующем добавления элемента в коллекцию произойдет перераспределения памяти и максимальное количество элементов увеличится в двое

◆ MaxCount

int Lotus.Core.SparseSet< TItem >.MaxCount
get

Максимальное количество элементов.

Максимальное количество элементов на данном этапе, если текущее количество элементов будет равно максимальному, то при следующем добавления элемента в коллекцию произойдет перераспределения памяти и максимальное количество элементов увеличится в двое.
