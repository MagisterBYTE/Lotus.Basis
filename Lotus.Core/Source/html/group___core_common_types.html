◆ TValueType

enum Lotus.Core.TValueType

Определение допустимых типов значений.

Определение стандартных типов данных значения в контексте использования универсального типа. Указанные типы данных имеют прямую поддержку в подсистеме сообщений. Также они охватываю более 90% функциональности которая требуется в проектах с поддержкой универсального типа. Для Unity определенна поддержка игровых объектов и наиболее распространённых ресурсов
