Detailed Description

Подсистема параметрических объектов обеспечивает представление и хранение информации в документоориентированном стиле.

Основной объект подсистемы — это параметрический объект который хранит список записей в формате имя=значения. При этом сама запись также может представлена в виде параметрического объекта. Это обеспечивает представления иерархических структур данных.
