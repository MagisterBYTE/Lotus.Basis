Detailed Description

Подсистема запроса и ответа определяет однотипный унифицированный набор типов для получения фильтрованных/сортированных/сгруппированных данных с разделением на страницы и формирования соответствующих запросов.

Between 

Между первым аргументом (меньшим) и вторым аргументом (большим).

Contains 

Аргумент(строка) может находиться в любом месте с учётом регистра. Аргумент(иной) значение должно присутствовать в аргументе массива.

StartsWith 

Аргумент(строка) должна находиться в начале с учётом регистра.

EndsWith 

Аргумент(строка) должна находиться в конце с учётом регистра.

Like 

Аргумент(строка) должна сравниваться с учётом оператора Like.

NotEmpty 

Не равно пустой или NULL строке. Аргумент НЕ требуется. Не равно значению NULL для иных объектов.

Empty 

Равно пустой или NULL строке. Аргумент НЕ требуется. Равно значению NULL для иных объектов.

IncludeAny 

Любой из проверяемых элементов списка должен находиться в массиве аргумента.

filter [1, 2] item01 [1,2,3] -> true item02 [4,2,3] -> true item03 [2,3] -> true item04 [1,2] -> true item05 [4,5] -> false

IncludeAll 

Все из проверяемых элементов списка должен находиться в массиве аргумента.

filter [1, 2] item01 [1,2,3] -> true item02 [4,2,3] -> false item03 [2,3] -> false item04 [1,2] -> true item05 [4,5] -> false

IncludeEquals 

Проверяемые элементы списка должен быть равны массиву аргумента.

filter [1, 2] item01 [1,2,3] -> false item02 [4,2,3] -> false item03 [2,3] -> false item04 [1,2] -> true item05 [4,5] -> false

IncludeNone 

Ни один из проверяемых элементов списка не должен находиться в массиве аргумента.

filter [1, 2] item01 [1,2,3] -> false item02 [4,2,3] -> false item03 [2,3] -> false item04 [1,2] -> false item05 [4,5] -> true
