Detailed Description

Определение интерфейса для представления ответа/результата операции.

Определение интерфейса для представления ответа/результата операции с типизированным значением результата выполнения операции.

Помимо основного назначения - характеристики успешности или неуспешности выполнения, может также нести дополнительную информацию.
