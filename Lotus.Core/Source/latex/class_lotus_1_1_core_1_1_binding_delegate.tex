\doxysubsection{Detailed Description}
Класс реализующий привязку данных между свойством/методом объекта модели и объекта представления. 

Реализация класса для связывания данных. Для связывания параметров используется технология Delegate.\+Create\+Delegate(\+Type, object, string) что обеспечивает более быстрое обновление свойств и полей.
