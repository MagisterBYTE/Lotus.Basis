\doxysubsection{Detailed Description}
Атрибут для отображения дочерних свойств объекта в одну линию при показе в списке. 

Функциональность атрибута реализуется атрибутом Lotus\+Reorderable\+Attribute 

Должен применяться для сложных типов, при этом дочерние поля/свойства должны иметь атрибут Lotus\+Column\+Attribute
