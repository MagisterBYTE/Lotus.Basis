\doxysubsection{Detailed Description}
Список на основе массива. 

Среди основных преимуществ использования собственного типа списка можно выделить\+:
\begin{DoxyItemize}
\item Обеспечивается более высокая скорость работы за счет отказа проверок границ списка.
\item Можно получить доступ непосредственно к родному массиву.
\item Также поддерживается сериализации на уровни Unity, с учетом собственного редактора.
\item Поддержка уведомлений о смене состояний коллекции.
\item Поддержка обобщенного интерфейса IList. 
\end{DoxyItemize}
