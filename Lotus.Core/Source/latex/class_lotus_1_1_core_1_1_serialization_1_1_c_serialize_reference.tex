\doxysubsection{Detailed Description}
Вспомогательный класс хранящий данные для связывания поля/свойства типа ссылочного объекта. 

При чтении ссылки на объект мы пытаемся найти объект по его сохраненным параметрам, однако может быть такая ситуация что этот объект еще не создан, и тогда мы должны повторить это процесс после загрузки всех объектов.
