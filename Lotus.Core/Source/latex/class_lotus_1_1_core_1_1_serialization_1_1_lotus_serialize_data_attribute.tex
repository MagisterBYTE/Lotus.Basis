\doxysubsection{Detailed Description}
Атрибут для указания того что тип самостоятельно предоставит данные для сериализации. 

Тип помеченный данным атрибутом должен обязательно реализовать статический метод с именем Lotus\+Serialize\+Data\+Attribute.\+GET\+\_\+\+SERIALIZE\+\_\+\+DATA который возвращает данные сериализации.
