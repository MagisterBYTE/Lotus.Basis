\doxysubsection{Detailed Description}
Атрибут для определения сериализации свойства/поля. 

Реализация атрибута для определения возможности сериализации свойства/поля. Соответственно определяет возможность сериализации на уровне типа объекта. Также атрибут позволяет определить под каким именем будет записано поле или свойство объекта в поток данных. Так как имя образует имя элемента/атрибута в формате XML то он должен подчинятся правилам использования допустимых символов.
