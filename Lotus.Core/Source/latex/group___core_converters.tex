\doxysubsubsection{Detailed Description}
Подсистема конвертации и преобразования данных обеспечивает единый механизм и точку входа для преобразования объекта в нужный тип. 

Преобразование происходит на основе детальной информации об объекте который надо преобразовать в нужный тип, поддерживается конвертация в том числе из строки или путём преобразования из объектов смежного типа.
