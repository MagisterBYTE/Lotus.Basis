\doxysubsection{Подсистема ECS}
\hypertarget{group___core_e_c_s}{}\label{group___core_e_c_s}\index{Подсистема ECS@{Подсистема ECS}}


Подсистема ECS -\/ это архитектурный шаблон представления объектов как правило игрового мира. ECS состоит из сущностей, к которым прикреплены компоненты содержащие данные, и системами, которые работают с компонентами сущностей. Компонент является носителем только данных и недолжен, как правило,содержать никакой логики.
