\doxysubsubsection{Detailed Description}
Общие методы расширения для базовых типов платформы NET. 

В подсистеме приведены только общие методы расширения базовых типов платформы NET направленных на унификацию функциональных возможностей. Специфичные методы расширения будут реализованы в соответствующих подсистемах.
