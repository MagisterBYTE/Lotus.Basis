\doxysubsubsection{Detailed Description}
Подсистема поддержки инспектора свойств обеспечивает расширенное описание и управление свойствами/полями объекта. 

Инспектор свойств (или инспектор объектов) представляет собой элемент управления, который позволяет управлять объектом посредством изменения его свойств (и не только свойств).

При этом этот элемент управления используется как в режиме разработки приложения, так и может использоваться в готовом приложении.

Данная подсистема прежде всего направлена на расширение возможностей инспектора свойств Unity и инспектора свойств \doxylink{namespace_lotus}{Lotus}. Поддержка стандартного инспектора свойств IDE при разработке обычных приложений не предусмотрена.\input{group___core_inspector_attribute}
