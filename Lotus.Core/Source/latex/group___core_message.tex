\doxysubsubsection{Detailed Description}
Централизованная подсистема сообщений. Подсистема сообщений предназначена для уведомления всех подписчиков о произошедшем событии посредством соответствующих издателей. 

\hypertarget{group___core_message_autotoc_md2}{}\doxysubsubsubsection{\texorpdfstring{Возможности/особенности}{Возможности/особенности}}\label{group___core_message_autotoc_md2}

\begin{DoxyEnumerate}
\item Возможность отправить сообщение любым подписчикам
\item Легкость реализации обработчика сообщений
\item Минимальные накладные расходы, высокая скорость работы
\item Низкая связность и зависимость подсистемы от других подсистем
\item Полностью интегрирована в систему \doxylink{namespace_lotus}{Lotus} в качестве основной
\end{DoxyEnumerate}\hypertarget{group___core_message_autotoc_md3}{}\doxysubsubsubsection{\texorpdfstring{Описание}{Описание}}\label{group___core_message_autotoc_md3}
Подсистема сообщений очень простая и основана на паттерне подписчик/издатель. Отправка сообщений происходит через издателя, и также возможно через статический метод центрального диспетчера сообщений (который создает при необходимости издателя по умолчанию) \doxylink{class_lotus_1_1_core_1_1_c_publisher}{Lotus.\+Core.\+CPublisher}. Для обработки сообщения нужно реализовать соответствующий интерфейс \doxylink{interface_lotus_1_1_core_1_1_i_lotus_message_handler}{Lotus.\+Core.\+ILotus\+Message\+Handler}. Компонент с реализаций интерфейса нужно зарегистрировать в либо диспетчере, либо в соответствующем издателе. Сообщения поступают в очередь и последовательно обрабатываются. Сообщения можно послать подписчикам издателя или через диспетчер всем подписчикам. Сообщения также можно послать из консоли(для Unity). Многие подсистемы реализует интерфейс сообщений для централизованного и унифицированного управления.\hypertarget{group___core_message_autotoc_md4}{}\doxysubsubsubsection{\texorpdfstring{Использование}{Использование}}\label{group___core_message_autotoc_md4}

\begin{DoxyEnumerate}
\item Реализовать интерфейс \doxylink{interface_lotus_1_1_core_1_1_i_lotus_message_handler}{Lotus.\+Core.\+ILotus\+Message\+Handler}
\item Зарегистрировать компонент в конкретном издателе \doxylink{class_lotus_1_1_core_1_1_c_publisher}{Lotus.\+Core.\+CPublisher}
\item Теперь можно посылать команды через издателя \doxylink{class_lotus_1_1_core_1_1_c_publisher}{Lotus.\+Core.\+CPublisher}
\item Методы диспетчер или издателя нужно использовать в ручную(непосредственно вызывать методы в нужных местах)
\end{DoxyEnumerate}
