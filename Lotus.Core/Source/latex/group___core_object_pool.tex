\doxysubsubsection{Detailed Description}
Объектный пул -\/ порождающий шаблон проектирования, набор инициализированных и готовых к использованию объектов. 

Когда системе требуется объект, он не создается, а берется из пула. Когда объект больше не нужен, он не уничтожается, а возвращается в пул. Представлена отдельно общая реализация и реализация в контексте использования игровых объектов Unity\hypertarget{group___core_object_pool_autotoc_md5}{}\doxysubsubsubsection{\texorpdfstring{Возможности/особенности}{Возможности/особенности}}\label{group___core_object_pool_autotoc_md5}

\begin{DoxyEnumerate}
\item Простая работа с пулом готовых объектов
\item Общая и специальная реализация для Unity объектов
\end{DoxyEnumerate}\hypertarget{group___core_object_pool_autotoc_md6}{}\doxysubsubsubsection{\texorpdfstring{Описание}{Описание}}\label{group___core_object_pool_autotoc_md6}
Подсистема пула предназначена для более эффективной работы с объектами путем их повторного использования вместо создания/уничтожения объектов при необходимости. Подсистема в первую очередь направлена на эффектность и скорость работы, а не удобство работы. Объекты, готовые к использованию хранятся в стеке, работа ведется через основной менеджер \doxylink{class_lotus_1_1_core_1_1_pool_manager}{Lotus.\+Core.\+Pool\+Manager}. Основные операции являются\+: взять объект из пула для его использования (метод \doxylink{class_lotus_1_1_core_1_1_pool_manager_a6af22e1bb7e00858f1706088f62af7ba}{Lotus.\+Core.\+Pool\+Manager.\+Take}) и положить объект который больше не нужен в пул (метод \doxylink{class_lotus_1_1_core_1_1_pool_manager_a37af33a75296cf409be6436d7bbadb16}{Lotus.\+Core.\+Pool\+Manager.\+Release}) В реализации для Unity объектов, дополнительно, в методах Take -\/ игровой объект активируется, в методе Release -\/ игровой объект деактивируется.\hypertarget{group___core_object_pool_autotoc_md7}{}\doxysubsubsubsection{\texorpdfstring{Использование}{Использование}}\label{group___core_object_pool_autotoc_md7}
