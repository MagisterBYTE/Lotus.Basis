\doxysubsubsection{Detailed Description}
Подсистема сериализации данных обеспечивает расширенный механизм сериализации данных в различные форматы данных. 

Фактически, подсистема является надстройкой над стандартным сериализатором Json, документом XML и бинарным потоком. Подсистема реализует сохранение и восстановление ссылочных данных, возможность динамического связывания и обновление существующих объектов, а также возможности самостоятельно записать/прочитать объектом свои данные.\hypertarget{group___core_serialization_autotoc_md8}{}\doxysubsubsubsection{\texorpdfstring{Возможности/особенности}{Возможности/особенности}}\label{group___core_serialization_autotoc_md8}

\begin{DoxyEnumerate}
\item Простая в использовании, зависимость только от Json.\+NET
\item Для каждого типа можно гибко определить объем данных для сериализации
\item Возможность на уровне объекта самостоятельно прочитать/записать свои данные
\item Возможность динамического связывания и обновление существующих объектов
\end{DoxyEnumerate}\hypertarget{group___core_serialization_autotoc_md9}{}\doxysubsubsubsection{\texorpdfstring{Описание}{Описание}}\label{group___core_serialization_autotoc_md9}
Подсистема основания на сериализаторах которые обеспечивают сериализацию данных в нужном формате\hypertarget{group___core_serialization_autotoc_md10}{}\doxysubsubsubsection{\texorpdfstring{Использование}{Использование}}\label{group___core_serialization_autotoc_md10}

\begin{DoxyEnumerate}
\item Указать соответствующие атрибуты для полей и свойств которые подлежат сериализации
\item Можно реализовать интерфейс \doxylink{interface_lotus_1_1_core_1_1_serialization_1_1_i_lotus_serialize_to_xml}{Lotus.\+Core.\+Serialization.\+ILotus\+Serialize\+To\+Xml} или \doxylink{interface_lotus_1_1_core_1_1_serialization_1_1_i_lotus_serialize_to_binary}{Lotus.\+Core.\+Serialization.\+ILotus\+Serialize\+To\+Binary} для самостоятельной записи/чтения данных объектом в соответствующий формат.
\item Можно реализовать интерфейс \doxylink{interface_lotus_1_1_core_1_1_serialization_1_1_i_lotus_serializable_object}{Lotus.\+Core.\+Serialization.\+ILotus\+Serializable\+Object}, добавить объект в словарь \doxylink{class_lotus_1_1_core_1_1_serialization_1_1_c_base_serializer_a9c600b131c12a74e7fd0667541c9337a}{Lotus.\+Core.\+Serialization.\+CBase\+Serializer.\+Serializable\+Objects} по ключу IDKey\+Serial, и тогда при последующей загрузки произойдет обновление данного объекта.
\item Для сохранения/загрузки использовать соответствующие методы Lotus.\+Core.\+Serialization.\+XSerialization\+Dispatcher
\end{DoxyEnumerate}
