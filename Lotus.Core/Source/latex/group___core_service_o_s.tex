\doxysubsubsection{Detailed Description}
Подсистема вспомогательных сервисов обеспечивает дополнительную рабочую функциональность, связанную с платформо-\/зависимыми реализациями и особенностями отдельных системных элементов. 

Сюда входит работа с диалоговыми окнами открытия/закрытия файла, объекта реализующего выполнения задачи в отельном потоке и работа с реестром Windows.
