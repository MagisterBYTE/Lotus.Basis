\doxysubsubsection{Detailed Description}
Подсистема задач (не потоки) предназначена для формирования задачи или группы задачи которая может выполняться последовательно или параллельно, с определенным режимом выполнения, а также с возможностью приостановки и дальнейшего выполнения. 

\hypertarget{group___core_task_autotoc_md11}{}\doxysubsubsubsection{\texorpdfstring{Возможности/особенности}{Возможности/особенности}}\label{group___core_task_autotoc_md11}

\begin{DoxyEnumerate}
\item Выполнение задачи по критериям интерфейса \doxylink{interface_lotus_1_1_core_1_1_i_lotus_task}{Lotus.\+Core.\+ILotus\+Task}.
\item Поддержка задержки начала выполнения, паузы, информирования о ходе выполнения задачи.
\item Работа с группами задач, возможность запускать последовательно и параллельно исполнения в группе.
\item Задержка при выполнение задач группы, информирования об окончании выполнения каждой задачи.
\end{DoxyEnumerate}\hypertarget{group___core_task_autotoc_md12}{}\doxysubsubsubsection{\texorpdfstring{Описание}{Описание}}\label{group___core_task_autotoc_md12}
Соответствующая задача формируется классом на основе реализации интерфейса. Под задачей понимается элементарная единица выполнения с правильно реализованным интерфейсов, выполняемая определённым способом с возможностью информирования об окончании задачи, паузой и принудительной остановкой выполнения задачи.

Под группой задач понимается несколько задач выполняемых параллельно или последовательно определённым способом(в том числе с задержкой) с возможностью информирования об окончании выполнения всех задач группы, паузой и принудительной остановкой выполнения группы задачи.\hypertarget{group___core_task_autotoc_md13}{}\doxysubsubsubsection{\texorpdfstring{Использование}{Использование}}\label{group___core_task_autotoc_md13}

\begin{DoxyEnumerate}
\item Правильно реализовать интерфейс \doxylink{interface_lotus_1_1_core_1_1_i_lotus_task}{Lotus.\+Core.\+ILotus\+Task}.
\item Сформировать задачу или группу задач и запустить на исполнение методами \doxylink{class_lotus_1_1_core_1_1_task_executor}{Lotus.\+Core.\+Task\+Executor} или \doxylink{class_lotus_1_1_core_1_1_task_group_executor}{Lotus.\+Core.\+Task\+Group\+Executor}
\item Методы исполнителя задач нужно использовать в ручную(непосредственно вызывать его методы в нужных местах)
\end{DoxyEnumerate}
