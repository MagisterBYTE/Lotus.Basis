\doxysubsection{Detailed Description}
Определение интерфейса для объекта(модели) который может быть недоступен. 

Обычно логика пользовательского интерфейса должно быть отделена от основной логики приложения, однако иногда бывает необходимость определять некоторые типовые действия в элементах пользовательского интерфейса и правильно на них реагировать. 

Благодаря реализации данному интерфейсу объект(модель) может реагировать когда он недоступен, а также корректно реагировать на этот статус.
