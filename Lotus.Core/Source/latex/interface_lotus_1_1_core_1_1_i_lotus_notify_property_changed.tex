\doxysubsection{Detailed Description}
Определение дополнительного интерфейса для нотификации об изменении данных. 

Указанный интерфейс является базой для реализации связывания данных. Он обеспечивает концепцию «издатель-\/подписчик», в рамках того что если объект является «издателем», т.\+е. другим объектам нужно знать об изменение его свойства, он обязательно должен правильно и безопасно реализовать указанный интерфейс
