\doxysubsection{Detailed Description}
Интерфейс для определения задачи. 

Под задачей понимается элементарная единица выполнения с правильно реализованным интерфейсов, выполняемая определённым способом с возможностью информирования об окончании задачи и принудительной остановкой выполнения задачи
