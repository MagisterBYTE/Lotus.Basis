\doxysubsection{Detailed Description}
Интерфейс для сериализации данных который обеспечивает сохраннее/загрузку данных самостоятельно объектом. в бинарный формат. 

Реализация интерфейса требуется если нужно как-\/то специфично записать/прочитать данные и классическая модель чтения/записи свойств и полей не подходит. 

Кроме этого реализация интерфейса позволяет меньше использовать рефлексию данных что положительно сказывается на общей скорости работы.
